📅 Event Hall Booking Web App
Event Hall Booking is a smart, user-friendly web application designed to simplify the process of booking and managing seminar halls for departmental events. Whether you're organizing a workshop, seminar, or conference, this app ensures a seamless booking experience for staff while empowering administrators with full control over the bookings.

🔗 Hosted Link:[ Event Hall Booking Web App](https://it-dept-event-hall-booking.vercel.app/)

🌟 Features
Staff Portal
Book Hall: Staff can quickly book seminar halls by specifying:
Event Name
Event Date
Venue (Seminar Hall 1 / Seminar Hall 2)
Staff Name (Coordinator)
User-Friendly Interface: Simplified form for booking events.
Admin Dashboard
View Bookings: View all upcoming and past bookings.
Manage Bookings: Update or delete bookings as needed.
Full Control: Gain insights into event schedules and ensure efficient venue management.
🛠️ Tech Stack
Frontend: React.js
Backend: Node.js + Express
Database: MongoDB
🚀 Deployment
Hosting Platform: Vercel
🎯 How It Works
Staff Login: Log in to book a venue for your event with ease.
Admin Login: Access the admin dashboard to oversee bookings and manage the event calendar.
Dynamic Updates: Ensure no double bookings by real-time slot management.
🖥️ Future Enhancements
Multi-slot selection for events spanning multiple time frames.
Notification system for booking confirmations and reminders.
Integration of advanced analytics for venue utilization reports.
📂 Project Structure
Frontend: Handles the booking form, staff portal, and admin dashboard UI.
Backend: Ensures smooth communication between the app and database for managing event data.
Database: Stores booking details and user information securely.
